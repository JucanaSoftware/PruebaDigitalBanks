# Prueba Técnica - Gestión de Usuarios

## Cómo ejecutar

1. Levantar primero el proyecto **Negocio (API)**.  
2. Luego levantar el proyecto **Presentación (Razor Pages)**.  
3. Abrir en el navegador la página de usuarios.

## Base de datos

- La base de datos queda en la capa de **Datos** en la carpeta `bd` en formato SQL (`BaseDatos.sql`).  
- Ejecutar este script para crear la tabla `Users` y el procedimiento almacenado `usp_Users_CRUD`.
